# HyoNova live chat — external test page

A static page on an origin that is not HyoNova's, used to prove that the HyoNova website chat
works on a customer's site. It is not a real shop. Open it with a widget id:

    https://mus22112211.github.io/hyonova-chat-test-site/?w=<widget id>

`?host=api` loads the chat from the older install address (api.hyonova.com) instead of
chat.hyonova.com. The widget must list `mus22112211.github.io` under its allowed domains.
